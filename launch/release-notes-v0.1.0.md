Initial public release of Opus Mode for Codex, an instruction-only Agent Skill
for long-running, context-heavy work.

- Compact task-state preservation and continuity across available context.
- Context synthesis and preservation of earlier decisions and constraints.
- Global consistency and evidence-based root-cause investigation.
- Focused falsification, proportional verification, and accurate completion claims.
- Concrete examples, a runnable feature-flag fixture, and a paired benchmark protocol.

This skill does not invoke Claude, call Anthropic, or switch the Codex model.
No controlled baseline-versus-skill improvement is claimed. See
[release validation](https://github.com/ncusspm25/opus-mode-for-codex/blob/v0.1.0/references/validation.md)
for the actual compatibility and smoke-test evidence.

Start with the [installation and usage guide](https://github.com/ncusspm25/opus-mode-for-codex/tree/v0.1.0#quick-start).
